THREE MINUTES TO FLOW

三步，把你的主力开发机连到口袋里

STEP 01

在目标电脑打开 Naro

安装并登录 codex、claude 或 agy，解压运行 Naro.app（macOS）或 Naro.exe（Windows）。

STEP 02

配置中继地址与密钥

在「设备连接 → 本机配对」填入中继 HTTPS 地址与连接密钥，点击连接即建立单条出站 WSS。

STEP 03

扫码或输码，随时接力

手机打开网页扫码，或在另一台电脑的 Naro 中输入设备地址与 8 位配对码，立即续写工作流。

SELF-HOST IN SECONDS

单文件 Go 中继，两分钟私有部署

无需数据库，无需 Redis。可直接运行单个 Go 二进制，或通过 Docker / Docker Compose 一键容器化部署。

NARO_PUBLIC_URL

中继公开 HTTPS 地址（协议 + 主机名 + 可选端口）

NARO_RELAY_TOKEN

中继与目标电脑共享的 32–512 位无空格随机密钥

NARO_RELAY_ADDR

中继监听地址，默认 127.0.0.1:7319

NARO_TLS_CERT / KEY

可选；由 Go 中继直接提供 HTTPS 时指定证书与私钥
